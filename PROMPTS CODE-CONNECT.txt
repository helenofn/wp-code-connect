RESULTADO:
Atalhos na raiz (package.json)

Comando	O que faz
pnpm dev	Sobe os dois apps juntos (web na porta 5173, api na porta 3000)
pnpm dev:web / pnpm dev:api	Sobe só um dos apps
pnpm build	Gera o build dos dois apps
pnpm build:web / pnpm build:api	Gera o build de um app só
pnpm lint	Roda o lint nos dois apps
pnpm test:api	Roda os testes do NestJS
pnpm web <cmd> / pnpm api <cmd>	Roda qualquer comando dentro de um app, sem trocar de diretório
